# pyapp scaffold

Application skeleton: src-layout with uv, ruff, mypy, pytest, plus a Windows
portable distribution flow built on embeddable Python + .pyc/.pyd + an .exe
launcher shell (tools/embedpack).

## Layout

```
pyapp/
├── pyproject.toml        # hatchling build, dependencies, ruff/mypy/pytest config (PEP 735 dev group)
├── justfile              # lint / fmt / type / test / pyd / dist / clean
├── embedpack.toml        # embedpack project description: app identity + dist deps
├── .python-version       # 3.14, uv interpreter pin
├── src/pyapp/            # application package (editable install; whole tree copied into dist)
│   ├── __main__.py       # shim shared by python -m pyapp and the packaged entry
│   ├── app.py            # CLI arguments, report output, --selftest
│   ├── core.py           # business module; shipped as .pyd after `just pyd`
│   └── py.typed
├── tests/                # pytest (runs the extension module once the .pyd is built)
├── tools/embedpack/      # vendored packer: build.py + prebuilt launcher shells
└── dist/                 # output: PyApp/ portable directory (gitignored)
```

## Development

```bash
uv sync          # .venv + editable pyapp install + dev toolchain (locked by uv.lock)
just lint        # ruff check + format check (tools/ covered by ruff check)
just type        # mypy --strict (packages=pyapp)
just test        # pytest
just fmt         # autofix + format
```

CLI: `uv run pyapp --points 500` (console script from pyproject [project.scripts]).

## Distribution

```bash
just pyd         # Cython compiles core.py to core.cp314-win_amd64.pyd (optional hardening)
just dist        # embeddable runtime + numpy (.pyc) + app (.pyc/.pyd) + PyApp.exe
just dist-gui    # pythonw variant (windowed)
```

Output: `dist/PyApp/PyApp.exe`, entry convention `app\__main__.pyc`. `--src-root`
copies the src/ tree into app/ (package semantics preserved, `import pyapp`
works) and relocates __main__.py to app/__main__.pyc. Pre-release check:
`dist\PyApp\PyApp.exe --selftest`.

## Conventions

- Build interpreter and embeddable runtime are both 3.14: .pyc bytecode locks to
  the X.Y magic number, pinned through .python-version by uv.
- Runtime dependencies are declared in pyproject [project] dependencies and
  reach dist by name via [dist].packages in embedpack.toml, copied per
  distribution RECORD; keep [dist].packages in sync with dependencies.
- embedpack.toml describes the project for `just dist`; CLI flags override it
  (CLI > config > defaults), machine flags (--embed-zip, --cache) stay on the
  command line.
- The .pyd is a build artifact (gitignored), regenerated by `just pyd`; dist
  ships .pyc until the .pyd exists (`--include "pyapp/*.pyd"` force-ships it
  past .gitignore).
- The dist app/ tree is enumerated by `git ls-files` under --src-root, so the
  project's .gitignore governs what ships; outside a git work tree everything
  ships past the floor excludes (trim with --exclude).
- Launcher shells (`templates/*.exe`) are build artifacts of the matching
  `.cs`; rebuild with the .NET Framework csc (`/target:winexe` for the GUI
  variant), e.g. `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`.
- Renaming the project: replace pyapp / PyApp globally, adjust .python-version,
  then `uv sync`.
